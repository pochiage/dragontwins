# デスクトップ自動整理（Mac）

毎週決まった日時に、デスクトップ上のファイル・フォルダをすべて「書類 > Desktop」の中の
月フォルダ（例：`2026 August`）へ移動します。どの月に入るかは移動した日（実行日）で決まります。
月フォルダに同じ名前のものが既にある場合は、上書きせずデスクトップに残します。

## セットアップ

1. このフォルダ（`desktop-organizer`）を Mac にダウンロードする
2. ターミナルでこのフォルダに移動し、移動先フォルダを指定して実行する

   ```bash
   ./install.sh "$HOME/Documents/Desktop"
   ```

3. **フルディスクアクセスを許可する**（これをしないとデスクトップを読めません）
   システム設定 → プライバシーとセキュリティ → フルディスクアクセス → `+` →
   `Cmd+Shift+G` で `/bin/bash` を入力して追加し、オンにする

4. 動作確認：下の「手動で実行する」の方法で1回実行し、ログを確認する

## 手動で実行する

- **ダブルクリック**：ホームの「アプリケーション」フォルダ（`~/Applications`）にある
  `デスクトップを整理.command` を開く（初回は右クリック →「開く」）
- **ターミナル**：

  ```bash
  launchctl kickstart gui/$(id -u)/com.user.organize-desktop
  ```

## 設定

- 実行日時：`install.sh` 冒頭の `WEEKDAY` / `HOUR` / `MINUTE`（初期値は毎週月曜 9:00）。変更したら `install.sh` を再実行してください
- 予定時刻にスリープしていた場合は、スリープ解除時に自動で実行されます。
  電源が切れていた場合はその週は実行されないので、手動で実行してください
- ログ：`~/Library/Logs/organize-desktop.log`（移動・スキップしたファイルが記録されます）

## 解除

```bash
./uninstall.sh
```
