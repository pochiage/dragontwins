# デスクトップ自動整理（Mac）

毎週決まった日時に、デスクトップ上のファイル・フォルダをすべて「書類 > Desktop」の中の
月フォルダ（例：`2026 August`）へ移動します。どの月に入るかは移動した日（実行日）で決まります。
月フォルダに同じ名前のものが既にある場合は、上書きせずデスクトップに残します。
「資料 (1).pdf」「資料（2）.pdf」「資料 のコピー.pdf」のようなコピーも、元のファイル
（資料.pdf）がデスクトップか移動先のどこかにあれば、移動せずデスクトップに残します。

## セットアップ（管理者権限は不要）

1. このフォルダ（`desktop-organizer`）を Mac にダウンロードする（デスクトップ以外の場所に置く）
2. ターミナルでこのフォルダに移動し、移動先フォルダを指定して実行する

   ```bash
   bash install.sh "$HOME/Documents/Desktop"
   ```

3. ホームの「アプリケーション」フォルダ（`~/Applications`）にある
   **デスクトップを整理.app** をダブルクリックして1回実行する
4. 「デスクトップフォルダ内のファイルへのアクセス」「書類フォルダ内の…」の
   確認が出たら **許可** を押す。完了すると結果がダイアログで表示されます（10秒で自動的に閉じます）

以降は毎週自動で実行されます。

## 手動で実行する

**デスクトップを整理.app** をダブルクリックします（Spotlight や Raycast からも起動できます）。
失敗したときはダイアログで理由が表示されます。

## 設定

- 実行日時：`install.sh` 冒頭の `WEEKDAY` / `HOUR` / `MINUTE`（初期値は毎週月曜 9:00）。変更したら `install.sh` を再実行してください
- 予定時刻にスリープしていた場合は、スリープ解除時に自動で実行されます。
  電源が切れていた場合はその週は実行されないので、手動で実行してください
- ログ：`~/Library/Logs/organize-desktop.log`（移動・スキップしたファイルが記録されます）

## 解除

```bash
./uninstall.sh
```
